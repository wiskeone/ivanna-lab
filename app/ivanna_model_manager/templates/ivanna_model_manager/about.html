Ivanna Lab

{% trans "Self-hosted LLM model lab — всё вокруг цикла «сделай свою модель», в Docker для одной GPU-машины." %}

{% trans "Реестр моделей · инференс и чат · fine-tuning (LoRA/RAFT/документы) · слияния (mergekit) · датасеты и дистилляция · RAG · оценка · GGUF · мягкий MoE без дообучения." %}

{% trans "Модели и веса" %}

{% trans "Модели и веса: импорт с Hugging Face и локальных путей, версии и чекпойнты, квантизация, конвертация в GGUF, слияния (linear/SLERP/TIES/DARE). Мягкий MoE — доменные эксперты из плотной модели без градиентов: активационный скан → steer-патч → гейты → роутер." %}

{% trans "Инференс" %}

{% trans "Инференс: чат-сессии с любой моделью реестра, сравнения моделей, пресеты генерации. Бэкенд на выбор: transformers в процессе или внешний vLLM (OpenAI-совместимый API)." %}

{% trans "Обучение" %}

{% trans "Обучение: Instruction / RAFT / document trainers на transformers+bitsandbytes, дистилляция Q&A учителями, ручные датасеты, импорт с HF Hub, очередь задач GPU/CPU воркеров." %}

{% trans "Качество" %}

{% trans "Качество: задачи оценки, сравнение моделей по датасетам, рейтинги ответов. RAG: коллекции PDF/DOCX/HTML/CSV, чанкинг, FAISS + BM25 гибрид." %}

{% trans "Стек" %}
BackendDjango 5 + DRF, Gunicorn
FrontendDjango-шаблоны + Bootstrap 5.3 (тёмная) + jQuery + Plotly
БД / очередьPostgreSQL 15, Redis 7 + Celery 5 (GPU и CPU воркеры, beat, Flower)
AItransformers, bitsandbytes, mergekit, sentence-transformers, FAISS, llama.cpp (скрипты конвертации)
МониторингPrometheus + Grafana, node/redis exporters
РантаймDocker, NVIDIA CUDA 12.8 (GPU-воркер), CPU-образ в комплекте
